# kofimovie

//subject to changes as project gets intense//

KofiMovie is a dynamic movie discovery web application built with vanilla HTML, CSS, and JavaScript.
It allows users to search for movies, view trending films, and explore detailed information using the TMDB API and Omdb API
The project is built as a Hybrid SPA with reusable components and modular JavaScript.

## Features

- Dynamic header and footer loaded via JavaScript modules
- Hybrid SPA architecture (multiple HTML entry points + dynamic content)
- Search movies using TMDB API + OMDb
- View detailed movie information
- Responsive layout
- Clean folder structure with reusable components

## Technologies Used

- HTML5
- CSS
- Vanilla JavaScript (ES Modules)
- TMDB API + OMDb
